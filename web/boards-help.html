Boards

A kanban board for each of your projects: To Do, In Progress, Needs you, Done. The tickets live in the project's own folder, so Claude works on them right where your code is.

Add a project

  1. In Claude desktop, open a Code session in your project's folder.
  2. Type /crewdeck and click Add this folder as a board.

Its board appears here in the rail a few seconds later. The folder must be a git project (Claude can make it one: ask it to "set up git in this folder").

In Terminal instead: ~/.crewdeck/bin/crewdeck add-project <name> <folder>
