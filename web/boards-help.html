Boards

A kanban for each of your projects.

  1. Open a Claude Code session in your project's folder.
  2. Type /crewdeck, then click Add as a board.
Details

Columns: To Do, In Progress, Needs you, Done. Tickets live in the project's own folder, so Claude works on them where your code is. The folder must be a git project: ask Claude to "set up git in this folder".

In Terminal: ~/.crewdeck/bin/crewdeck add-project <name> <folder>
